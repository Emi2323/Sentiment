# Sentiment classification of movie reviews

Logistic regression (TF-IDF features) vs. a majority-class baseline on the
NLTK Movie Reviews corpus (positive/negative).

## Files
- Assignment2.ipynb: all the code (tuning, results tables, learning curves)
- movie_reviews.csv: the 2,000 reviews used (columns: text, label)
- Assignment 2_Enkhbaatar_NLP.pdf: the report

## How to run
Open Assignment2.ipynb in Google Colab and choose Runtime > Run all.
The notebook downloads the NLTK corpus itself. The random seed is fixed (42),
so the numbers match the report.
